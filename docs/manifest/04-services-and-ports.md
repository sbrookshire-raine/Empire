# 04 — Services and ports

## Port table

| Service | URL | Managed by EMPIRE | Health check |
|---------|-----|-------------------|--------------|
| **Frontend** | http://127.0.0.1:8080 | Yes (`start-frontend.ps1`) | `GET /api/memory/status` |
| **PocketBase** | http://127.0.0.1:8090 | Yes | `GET /api/health` |
| **PocketBase admin** | http://127.0.0.1:8090/_/ | — | Web UI |
| **Eve** | http://127.0.0.1:2000 | Yes (`start-eve.ps1`) | `GET /eve/v1/info` |
| **Ollama** | http://localhost:11434 | No (user/OS) | `GET /api/tags` |
| **Ollama OpenAI-compat** | http://localhost:11434/v1 | No | Used by Eve + Cognee LLM |
| **Postgres (Cognee)** | localhost:5432 | Docker (`ensure-cognee-postgres.ps1`) | `psycopg` from memory_api |

All application bindings are **loopback only** in default configuration.

## Start order

Defined in `config/services.json` → `rollInOrder`:

```
ollama → pocketbase → frontend → eve
```

**Preferred single command:**

```powershell
.\scripts\start-stack.ps1
```

Assumes Ollama already running. Stack script handles VHDX mount, Postgres, PocketBase, frontend, Eve.

### Manual start (troubleshooting)

```powershell
# 1
ollama serve

# 2
.\scripts\start-pocketbase-background.ps1

# 3
.\scripts\start-frontend.ps1

# 4
.\scripts\start-eve.ps1
```

## Stop order

`rollOutOrder` in `config/services.json`:

```
eve → frontend → pocketbase
```

```powershell
.\scripts\roll-out.ps1
```

Ollama and Docker Postgres are not stopped by roll-out by default.

## Service details

### Ollama

- **Not** started by EMPIRE scripts (`managed: false` in services.json)
- Chat models selected via Workbench or Eve `switch_chat_model`
- Embed model for Cognee configured in `config/cognee.env` (`EMBEDDING_MODEL`)

### PocketBase

- Binary: `backend/pocketbase/pocketbase.exe` (downloaded by setup, gitignored)
- Data: `backend/pocketbase/pb_data/` (gitignored)
- Migrations: `backend/pocketbase/pb_migrations/`
- Serves on `127.0.0.1:8090`

### Frontend (`python -m frontend.serve`)

- Serves static files from `frontend/`
- Implements `/api/*` routes (memory, ollama, eve proxy, services, primitives, wiki)
- Default port **8080** (see `serve.py` `main()`)

### Eve

- Built output: `agents/empire-task-agent/.output/`
- Started via `npm exec eve start --host 127.0.0.1 --port 2000`
- `scripts/ensure-eve-build.py` rebuilds when agent sources change
- Env from `config/services.json` start block + `.env.local`

### Postgres (Cognee)

- Docker container `empire-cognee-postgres`
- Credentials in `config/cognee.env` (`cognee` / `cognee` / `cognee_db`)
- Graph + vector data under `SYSTEM_ROOT_DIRECTORY` (`V:\Cognee`)

## Dashboard

http://127.0.0.1:8080/dashboard.html

- Reads `frontend/dashboard-status.json` (regenerated by `refresh-dashboard.ps1`)
- Shows service states from `config/services.json`
- Can start/repair managed services via `POST /api/services/start`
