## Getting Started

### Introduction

*A factual overview of the current PrompTessor prompt workflow.*

**Source:** https://promptessor.com/docs

#### Definition

PrompTessor is an AI prompt workspace for creating, improving, reverse-engineering, saving, and reusing prompts for AI tools.

#### Workflow

How this feature fits into the prompt workflow.

- Start from an idea, task, existing prompt, image, video, text, or URL.
- Use the generator, optimizer, analysis, refinement, or Reverse Prompt workflow depending on the input.
- Review the generated or improved prompt with analysis, reasoning, expected output, model fit, and practical guidance.
- Save useful prompts to the Prompt Library for private reuse, community sharing, or official collections.

#### Outputs

What users can expect from the feature.

- Structured prompts for text, image, video, coding, writing, business, and creative AI tools.
- AI Prompt Analysis with scoring, strengths, weaknesses, metrics, token estimates, use cases, and model suggestions.
- Optimized and refined prompt versions that can be reused across AI systems.
- A prompt history and Prompt Library for keeping useful prompts organized.

#### Core Workflow

PrompTessor combines multiple prompt workflows in one workspace.

Generate prompts from ideas, tasks, briefs, or goals.

Analyze prompt quality with scoring, metrics, weaknesses, strengths, token estimates, and model guidance.

Optimize existing prompts into clearer and more specific versions.

Refine generated, optimized, or reverse-engineered prompts with user feedback.

Reverse-engineer prompts from images, videos, text, or URLs.

Save useful prompts to a reusable Prompt Library for private use, community sharing, or official collections.

#### Definition

A AI Prompt Generator is a tool that turns an idea, goal, task, brief, or reference context into a structured prompt with a clear role, context, instructions, constraints, and expected output for an AI system.

How this feature fits into the prompt workflow.

### AI Prompt Optimizer

*Improve existing prompts by making them clearer, more specific, and easier for AI models to follow.*

**Source:** https://promptessor.com/docs/prompt-optimizer

#### Definition

Prompt optimization is the process of improving an existing prompt so it gives an AI tool clearer instructions, stronger context, better goal alignment, more useful constraints, and a more reliable output structure.

#### Workflow

How this feature fits into the prompt workflow.

- Start with an existing prompt that produces vague, incomplete, inconsistent, or hard-to-control outputs.
- Paste the prompt into AI Prompt Optimizer and include any target model, audience, output format, constraints, or known failure symptoms when available.
- PrompTessor reviews the prompt for clarity, specificity, context, goal orientation, structure, constraints, and model fit.
- Review optimized versions, reasoning, expected output, implementation guidance, token estimates, and suggested use cases.
- Choose the strongest version, refine it with feedback if needed, test it in the target AI tool, or save it to the Prompt Library.

#### Outputs

What users can expect from the feature.

- Optimized prompt versions with clearer wording, stronger context, better structure, and more useful constraints.
- Reasoning that explains what changed and why the optimized version should perform better.
- Prompt quality metrics covering clarity, specificity, context, goal orientation, structure, and constraints.
- Implementation guidance, token estimates, suggested use cases, and compatible model categories.

Use AI Prompt Optimizer when you already have a prompt and want to improve the quality of its instruction.

### AI Prompt Analysis

**Source:** https://promptessor.com/docs/prompt-analysis

#### Definition

Prompt analysis is the process of evaluating an existing prompt to explain how well it is likely to perform, what is working, what is missing, and what should be improved before the prompt is reused, optimized, or saved.

#### Workflow

How this feature fits into the prompt workflow.

- Start with an existing prompt, generated prompt, optimized prompt, or prompt draft that needs evaluation.
- Add optional context, reference images, target model, audience, output format, or known issues when available.
- PrompTessor reviews the prompt for clarity, specificity, context, goal orientation, structure, constraints, and model fit.
- Review the overall score, metric breakdown, strengths, weaknesses, token estimates, suggested use cases, model guidance, and prompt usage guide.
- Use the findings to optimize, refine, rewrite, test, compare, or save the prompt.

#### Outputs

What users can expect from the feature.

- Overall prompt quality score with reasoning.
- Six prompt quality metrics: clarity, specificity, context, goal orientation, structure, and constraints.
- Strengths and weaknesses written as practical feedback for improvement.
- Estimated input and output token usage.
- Suggested use cases, compatible AI models, prompt usage guidance, optimized versions, and implementation advice.

#### When to Use AI Prompt Analysis

Use AI Prompt Analysis when you need to understand prompt quality before rewriting, optimizing, saving, or running it in an AI tool.

You have a prompt, but the AI output is inconsistent, generic, incomplete, or hard to evaluate.

You want to know whether a prompt has enough clarity, specificity, context, structure, and constraints.

You need to compare prompt versions before choosing which one to use or save.

You want model guidance, token estimates, strengths, weaknesses, and practical next steps before improving the prompt.

#### When to Use Prompt Library

Use Prompt Library when a prompt becomes useful enough to reuse, share, organize, or discover later.

You have a final prompt from generation, analysis, optimization, refinement, or Reverse Prompt that should not be lost in chat history.

You want a private collection for recurring personal, business, creative, coding, research, or team workflows.

You want to share useful public prompts with the PrompTessor community or browse prompts shared by other users.

You need prompt metadata, usage guidance, examples, recommended models, token estimates, category, and visibility in one reusable entry.

#### Library Scopes

Prompt Library separates ownership, sharing, and discovery states.

#### My Prompts

Prompts owned by the user, including private prompts and public prompts the user created.

#### Community Prompts

Public prompts shared by PrompTessor users for discovery and reuse.

#### Official Prompts

Prompts curated by PrompTessor separately from community submissions.

#### Saved Prompts

Public prompts the user saved so they can return to them later.

#### Upvoted Prompts

Public prompts the user upvoted because they found them useful.

#### Private and public visibility

Private prompts stay in My Prompts. Public prompts can appear in community discovery and receive engagement.

#### Prompt Library Metadata

A library entry stores the details needed to understand and reuse a prompt later.

#### Core fields

Title, prompt text, description, category, visibility, creation date, and update date.

#### Usage guidance

What this prompt does, tips for this prompt, and how to use the prompt.

#### Model guidance

Recommended AI models or tools that the prompt works well with.

#### Examples

Optional example text, example images, or output examples that show what the prompt can produce.

#### Token estimates

Estimated input and output token usage when the prompt has token data.

#### Discovery signals

Author information, official status, saved state, pinned state, upvotes, and ownership state.

#### Prompt Library vs Prompt History

Both preserve prompt work, but they serve different jobs.

#### Prompt Library

Stores selected prompts as reusable assets with metadata, categories, examples, visibility, model guidance, and discovery states.

#### Prompt History

Tracks past prompt activity and previous workflow results, but not every history item is curated enough to become a reusable library entry.

#### Best Practices

A stronger library entry is easier to understand, find, and reuse later.

Save prompts that solve a repeatable problem instead of saving every draft.

Use a clear title and category so the prompt can be found later.

Add description, usage guidance, recommended models, and examples when the prompt may be reused by another person or by your future self.

Keep sensitive prompts private unless they are safe and useful for public community discovery.

Use public visibility only when the prompt is safe to share and does not include private data, protected content, or internal context.

Update or delete prompts when they become outdated, inaccurate, duplicated, or no longer useful.
