## Suggested learning path

1. **Foundations** — Part 1: Get Started, Agent, and Customizing Cursor (installation, quickstart, models, core agent workflow, rules/skills/hooks/MCP).
2. **Extending Cursor** — Part 2: Cloud Agents (background/remote agents, Bugbot, automations), Integrations (Slack, GitHub, Jira, etc.), and the TypeScript/Python SDKs for programmatic control.
3. **Operating at scale** — Part 3: CLI (terminal-based agent usage, scripting, headless/CI use) and Account/Enterprise (teams, SSO, security, compliance, deployment patterns).

## Excluded / out-of-scope content

- **Product changelog** (`https://cursor.com/changelog`, ~1.25M characters raw) was excluded from this guide. It is an extremely long, repetitive, chronological release-notes log with low standalone learning value — not suited to a learning plan. Refer to it directly on the Cursor website if you need release-by-release history.
- **Help Center** pages (`https://cursor.com/help/...`) were excluded — they live under a different path prefix (`/help/` vs `/docs/`) and are support/FAQ-style content rather than the core product documentation requested.
- Non-English localized versions of the docs (available under `/es/docs/`, `/ja/docs/`, etc.) were excluded — only English content was scraped.
