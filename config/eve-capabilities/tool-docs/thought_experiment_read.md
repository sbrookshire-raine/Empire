## Description (verbatim from the tool schema, pre-R-03)

List or read the Architect's saved thought-experiment notes under 04_Thought_Experiments. Use before starting a new experiment, to build on what was already tried.

## Parameters

- `name` — Note name (or path inside 04_Thought_Experiments) to read in full.
