Autonomous Logic: Goal-Based Loops (Karpathy Style) \#\#\#\#\# 5.1 Loop Conceptual Framework "Auto Research" methodology: The agent operates as an autonomous researcher, removing the "human meat-suit" bottleneck from the iterative optimization loop. \#\#\#\#\# 5.2 Goal vs. Prompting \* **Prompting:** Single-attempt execution. \* **Goal-Seeking (** **/goal** **):** Iterative seeking. Executes, measures outcome against metrics, and self-modifies code until the goal condition is satisfied. \#\#\#\#\# 5.3 Evaluator Cartridges Deterministic feedback models used as stop-conditions for the loop. \* **Humanify:** Text naturalism/predictability scorer. \* **Hamo AI:** Marketing effectiveness metric (based on high-performance data). \* **Open-Rate Predictor:** CTR/Engagement probability algorithm. \#\#\#\#\# 5.4 Implementation Logic 1\. **Metric Definition:** Set numeric target (e.g., "Score \> 9/10" or "Lap time \< 40s"). 2\. **Constraint Scoping:** Restrict write access to specific files (e.g., driver.js or signal.draft). 3\. **Autonomous Iteration:** Agent runs experiments and loops until the evaluator cartridge returns the target score or attempt limit is hit. \#\#\#\# 6\.
