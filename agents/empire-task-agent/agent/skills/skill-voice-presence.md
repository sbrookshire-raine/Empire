# skill-voice-presence

1. Toolbelt **Voice Presence** on; speech API at `EMPIRE_VOICE_BASE_URL` (default :8000).
2. `voice_transcribe` for local audio paths; `voice_speak` for short TTS.
3. If health fails, say the speech server is down and point to `docs/VOICE_PRESENCE.md` — do not fake transcripts.
