# 3. The Project Initiation Protocol (my task)

Action: Create a template in your primary workspace (Heptabase, Notion, or Obsidian) called Project_Initiation.md. Before you write a single line of code or open an AI chat for a new idea, force yourself to fill in these blanks:

The North Star: (What is the real-world purpose? What is explicitly NOT the purpose?)

The Emergency Brake (Definition of Done): (What exact technical condition marks this as 100% complete so I can abandon it without guilt?)

The Core Loop: (One sentence explaining the baseline function.)

The User Flow: (Literal step-by-step path.)

The Data Schema: (Exact variables to track.)

The Graveyard: (List 3 "fun" features you are banning yourself from building right now.)

You will feed this completed template to the AI as your very first prompt.
